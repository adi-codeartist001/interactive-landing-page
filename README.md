# Interactive Landing Page

A responsive product landing page built with vanilla HTML, CSS, and JavaScript. No frameworks, no libraries — just clean front-end fundamentals.

The nav changes style as you scroll — picks up a frosted glass background and border once you leave the top of the page. Links have an underline animation on hover. On smaller screens the nav collapses into a hamburger menu that toggles a full-width mobile drawer.

## What's in it

- Scroll-based navbar styling using a `scroll` event listener and `classList.toggle`
- Hover-driven underline animations via CSS `::after` pseudo-elements and `width` transitions
- Responsive hamburger menu with open/close state tracked in JS
- Active section highlighting — the correct nav link highlights as you scroll past each section
- Fully responsive layout from 320px to 1440px using CSS Grid and `clamp()`

## Tech

HTML · CSS · JavaScript (no dependencies)
